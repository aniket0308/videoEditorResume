# Video Editor Portfolio

## Update your site
Open **js/data.js**. That is the only file you edit.
- New project: copy one block inside `projects`, paste at the top, change the text.
- New client review: copy a block inside `reviews` (`type: "video"` or `type: "text"`).
- Images go in `images/`, videos in `videos/`, then write the path, e.g. `images/promo.jpg`.

## Videos
Best: upload to YouTube (Unlisted) and paste the link. Vimeo and Google Drive links also work.
Local .mp4 files work, but GitHub blocks files over 100 MB and large videos load slowly.

## Put it on GitHub
1. Create a repository (e.g. `portfolio`) and upload all these files (index.html at the top level).
2. Repository > Settings > Pages > Source: "Deploy from a branch" > `main` / `(root)` > Save.
3. After a minute your site is live at `https://YOUR-USERNAME.github.io/portfolio/`.
To update later: edit data.js on GitHub, commit, and refresh the site.
